# Changelog

All notable changes to this project are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.2.0 - 2026-08-19

### Added

- CDC Clear Communication stylebook.
- NHS Health Content stylebook.
- SEC Plain English stylebook.
- W3C Technical Reports stylebook.
- NASA Technical Writing stylebook.
- `CATALOG.md` for task-oriented browsing.
- A style chooser, prompt comparison, and original before-and-after examples in the README.
- Stylebook request and problem-report issue forms.
- Source-level provenance records for the five additions.
- ASD-STE100 integration recommendation and v0.2 release notes.
- Validator checks for the 16-skill inventory and original-skill byte integrity.

### Changed

- Improved repository presentation, navigation, installation examples, compatibility notes,
  contribution guidance, source audit, and style matrix.
- Updated plugin metadata to prepare the 16-stylebook v0.2.0 package.

The behavior and contents of the original 11 skills are unchanged.

## 0.1.0 - 2026-08-18

### Added

- Initial catalog of 11 source-grounded editorial-system skills.
- Portable Agent Skills layout, Codex and Claude plugin manifests, installation guidance,
  compatibility evidence, provenance audit, examples, and standard-library validator.
